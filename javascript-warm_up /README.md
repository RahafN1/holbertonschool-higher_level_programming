# JavaScript - Warm up

## Description
This project is part of the Holberton School / ALX **Higher Level Programming** curriculum. It is an introduction to JavaScript, used here for scripting purposes (similar to how Python was used earlier in the curriculum). The goal is to master the fundamentals of the language before moving on to front-end development and making the AirBnB project dynamic with JavaScript and jQuery.

In this project, we focus on:
- Writing and running basic JavaScript scripts with Node.js
- Declaring variables and constants (`var`, `let`, `const`)
- Understanding JavaScript data types
- Using conditional statements (`if`, `if...else`)
- Using loops (`while`, `for`) and loop control (`break`, `continue`)
- Writing and using functions
- Understanding variable scope
- Using arithmetic operators
- Manipulating objects (dictionaries) and arrays
- Importing/requiring files in Node.js

## Installation
1. Clone the repository:
   ```
   git clone https://github.com/<your-username>/holbertonschool-higher_level_programming.git
   ```
2. Move into the project directory:
   ```
   cd holbertonschool-higher_level_programming/javascript-warm_up
   ```
3. Make sure Node.js 14.x is installed:
   ```
   curl -sL https://deb.nodesource.com/setup_14.x | sudo -E bash -
   sudo apt-get install -y nodejs
   ```
4. Make the scripts executable and run them directly:
   ```
   chmod +x ./0-javascript_is_amazing.js
   ./0-javascript_is_amazing.js
   ```

## Requirements
- Allowed editors: `vi`, `vim`, `emacs`
- All files are interpreted on **Ubuntu 20.04 LTS** using **Node.js (version 14.x)**
- All files should end with a new line
- The first line of every file must be exactly `#!/usr/bin/node`
- A `README.md` file at the root of the project folder is mandatory
- Code must be `semistandard` compliant (version 16.x.x), following [Standard rules](https://standardjs.com/rules.html) plus semicolons, with [AirBnB style](https://github.com/airbnb/javascript) as an additional reference
- All files must be executable
- File length is checked using `wc`

### Installing semistandard
```
sudo npm install semistandard --global
```
Run it against a file with:
```
semistandard ./0-javascript_is_amazing.js
```

## Learning Objectives
By the end of this project, you should be able to explain:
- Why JavaScript programming is amazing
- How to run a JavaScript script
- How to create variables and constants
- The differences between `var`, `const`, and `let`
- All the data types available in JavaScript
- How to use `if` and `if...else` statements
- How to use comments
- How to assign values to variables
- How to use `while` and `for` loops
- How to use `break` and `continue` statements
- What a function is and how to use functions
- What a function without a `return` statement returns
- Scope of variables
- The arithmetic operators and how to use them
- How to manipulate a dictionary (object)
- How to import a file
