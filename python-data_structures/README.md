# python-data_structures

## Holberton School - Higher Level Programming

This project covers basic Python data structures: lists and tuples, and how to manipulate them — accessing, modifying, iterating, and analyzing data within them.

## Requirements
- Ubuntu 20.04 LTS, Python 3 (version 3.4.3)
- All files end with a new line
- The first line of all files is exactly `#!/usr/bin/python3`
- Code follows pycodestyle (version 2.7.*)
- All files must be executable
- All modules, classes, and functions must have documentation

## Tasks

### 0. Print a list of integers
File: `0-print_list_integer.py`
Prints all integers of a list, one per line.

### 1. Element at index
File: `1-element_at.py`
Retrieves an element from a list at a specific index.

### 2. Replace in list
File: `2-replace_in_list.py`
Replaces an element of a list at a specific position.

### 3. Print reversed list of integers
File: `3-print_reversed_list_integer.py`
Prints all integers of a list, in reverse order.

### 4. New in list
File: `4-new_in_list.py`
Replaces an element of a list at a specific position, returning a new list.

### 5. No C
File: `5-no_c.py`
Removes all characters `c` and `C` from a string.

### 6. Print matrix of integers
File: `6-print_matrix_integer.py`
Prints a matrix of integers.

### 7. Add tuple
File: `7-add_tuple.py`
Adds two tuples.

### 8. Multiple returns
File: `8-multiple_returns.py`
Returns the first letter of a string and the length of that string.

### 9. Max integer
File: `9-max_integer.py`
Finds the biggest integer of a list.

### 10. Divisible by 2
File: `10-divisible_by_2.py`
Returns a list of booleans for each integer in a list, depending on whether it's divisible by 2.

### 11. Delete at
File: `11-delete_at.py`
Deletes an item from a list at a specific position.
