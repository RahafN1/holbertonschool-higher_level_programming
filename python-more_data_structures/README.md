# Python - More Data Structures: Set, Dictionary

## Holberton School - Higher Level Programming

This project covers more advanced Python data structures: sets, dictionaries, and 2D matrices, including manipulation, search, and modification operations.

## Requirements
- Ubuntu 20.04 LTS, Python 3 (version 3.4.3)
- All files end with a new line
- First line of all files: `#!/usr/bin/python3`
- Code follows pycodestyle (version 2.7.*)
- All files must be executable
- All modules, classes, and functions must have documentation

## Tasks

### 0. Squared simple
File: `0-square_matrix_simple.py`
Computes the square value of all integers of a matrix.

### 1. Search and replace
File: `1-search_replace.py`
Replaces all occurrences of an element by another in a new list.

### 2. Unique addition
File: `2-uniq_add.py`
Adds all unique integers in a list (only once each).

### 3. Present in both
File: `3-common_elements.py`
Returns a set of common elements in two sets.

### 4. Only differents
File: `4-only_diff_elements.py`
Returns a set of all elements present in only one set.

### 5. Number of keys
File: `5-number_keys.py`
Returns the number of keys in a dictionary.

### 6. Print sorted dictionary
File: `6-print_sorted_dictionary.py`
Prints a dictionary by ordered keys.

### 7. Update dictionary
File: `7-update_dictionary.py`
Replaces or adds key/value in a dictionary.

### 8. Simple delete by key
File: `8-simple_delete.py`
Deletes a key in a dictionary.

### 9. Multiply by 2
File: `9-multiply_by_2.py`
Multiplies all values in a dictionary by 2.

### 10. Best score
File: `10-best_score.py`
Returns a key with the biggest integer value.

### 11. Multiply by using map
File: `11-multiply_list_map.py`
Multiplies all integers of a list by a number, using `map`.

### 12. Roman to Integer
File: `12-roman_to_int.py`
Converts a Roman numeral to an integer.

### 13. Weighted average! (Advanced)
File: `13-weight_average.py`
Returns the weighted average of a list of tuples (element, weight).

### 14. Squared by using map (Advanced)
File: `14-square_matrix_map.py`
Computes the square value of a matrix, using `map`.

### 15. Delete by value
File: `100-delete_by_value.py`
Deletes all keys with a specific value in a dictionary.
